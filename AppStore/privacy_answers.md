# App Store 隐私问卷草稿

## Tracking

- Does this app track users? **No**
- Does this app use third-party data for tracking? **No**

## Data Collection

- Does this app collect data from this app? **No, Data Not Collected**

## 说明

- 截图、区域录屏、录制声音、导入图片、OCR 文字、翻译结果、标注项目和历史索引仅保存在用户 Mac 本地。
- 应用不包含广告 SDK、分析 SDK、远程日志、远程崩溃收集或开发者服务器。
- Apple Translation 语言资源由 macOS 管理；LocalShot 不把截图或 OCR 内容发送给开发者。
- 屏幕捕获和麦克风权限属于系统权限使用，不等于向开发者收集屏幕或声音内容。

提交前需再次扫描最终 Archive 及所有依赖；只有扫描结果仍无网络和第三方 SDK 时，才能在 App Store Connect 选择 “Data Not Collected”。
