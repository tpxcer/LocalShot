# App Review 审核说明草稿

## 登录

应用没有账号系统，不需要演示账号或密码。

## 核心测试步骤

1. 启动后，LocalShot 显示在 macOS 菜单栏，不主动显示 Dock 图标。
2. 从菜单选择“区域截图”，或使用设置页显示的区域截图快捷键。
3. 首次使用时，macOS 会请求屏幕捕获权限。允许后重新触发截图。
4. 拖动选择区域，可使用工具栏添加箭头、矩形、文字、马赛克或模糊，然后点击完成按钮复制结果。
5. “区域长截图”需要在单个可捕获窗口内选择区域；开始后由测试人员使用鼠标滚轮或触控板滚动，点击“完成”结束拼接。
6. 在 macOS 15 或更高版本选择“区域录屏”，框选区域后可在悬浮控制条选择系统声音和麦克风，再点击“开始录制”；红色边框会持续显示，停止后在 Finder 中定位本地 MP4。
7. OCR 使用 macOS Vision；翻译使用 Apple Translation。系统可能按语言组合提示下载由 macOS 管理的语言资源。

## 屏幕捕获说明

- 每次捕获都由用户主动点击菜单、工具栏或快捷键发起。
- 区域截图显示选区边框；长截图同时显示持续边框、采集状态、预览和完成/取消按钮。
- 区域录屏显示持续红框、红色状态点、计时和停止按钮；系统声音默认开启，麦克风默认关闭并只在用户主动开启时请求权限。
- 截图和录制内容只保存在本机，不上传到开发者服务器。

## 网络与数据

- 应用不包含账号、广告、分析、追踪、云同步或开发者服务器。
- OCR、标注、历史搜索均在本机完成。
- Apple Translation 所需系统语言资源由 macOS 管理。
