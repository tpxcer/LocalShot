# Mac App Store 截图计划

Apple 接受 16:10 的 1280×800、1440×900、2560×1600 或 2880×1800。首版统一输出 2880×1800 PNG，不制作视频预览。

建议画面：

1. 区域截图与完整工具栏：展示选区、箭头、矩形、步骤编号、文字和完成按钮。
2. 区域长截图：展示持续选区边框、实时长图预览和完成/取消。
3. 马赛克与模糊：展示两种遮挡效果和属性选择。
4. 本地 OCR：展示文字块识别和复制入口。
5. 原位置翻译：展示译文覆盖、原文切换和图片导出。
6. 本地历史：展示缩略图、搜索、类型筛选和保留设置。

制作规则：

- 只使用项目虚构测试内容或专门制作的演示文档，不显示用户桌面、账号、邮箱、文件名或其他隐私信息。
- 不添加未在应用中真实存在的功能和按钮。
- 可加入简短标题，但不得遮挡关键界面或暗示云同步、GIF/全屏录制等不存在的功能。
- 最终截图必须来自商店签名或 TestFlight 安装版，并在上传前逐张肉眼核对。
